Quick start

Two ways to work:

A. Map Maker → Layout (all in this tool). Upload your data in Map Maker, filter and symbolize it, then click Send to Layout — your styled map arrives as a map frame with the scale already calibrated and a legend built from your symbology.

B. ArcGIS Online → Layout. Style your map in ArcGIS Online, export an image with the Print widget, and upload it in the Layout module via Map Frame. Calibrate the scale bar by drawing a reference line of known distance.

Map Maker basics.

Add GeoJSON, CSV (with lat/long columns), or zipped shapefiles. Select a layer to set its symbology (single, categories, graduated colour with equal interval / quantile / natural breaks / manual classification, graduated symbol size), filters, and labels. The attribute table includes the filter builder and Field Calculator (e.g. rate = crimes / pop * 1000). Spatial tools: buffer, select by location, points-in-polygons statistics, clip, erase, intersect, union, dissolve, merge, centroids, convex hull, bounding box, simplify, nearest-neighbour join, and distance matrix. The ⬇ button on each layer exports valid GeoJSON (works in ArcGIS Online) or CSV — including any calculated fields. The ⟨ ⟩ buttons collapse the side panels to maximize the map.

Layout basics.

Start from a Template if you like. Add title, text, legend, north arrow, scale bar, neatline, images. Everything drags, resizes, and rotates. Undo with Ctrl+Z. The Margins button shows 0.5" margin guides (never exported). A Live Embed shows an interactive ArcGIS map on screen for reference but prints as a placeholder — use a real image frame for submission.

Scale bars.

Scale bars link to a map frame. Frames sent from Map Maker are calibrated automatically. For uploaded images, select the frame, click Calibrate scale, click two points with a known real-world distance between them, and enter the distance. The bar resizes automatically if you resize the frame.

Saving and exporting.

Save project downloads a JSON file with your data, styling, and layout — reload it anytime with Load project. Nothing is uploaded to a server. Export produces a print-ready PNG or PDF at Letter/A4/Tabloid size.

Layout templates

Templates give you a conventional starting arrangement — everything stays editable. Applying a template replaces the current page contents.

Spatial tools

Send map to Layout

The current map view will be captured as a high-resolution image and placed on the layout page, with the scale calibrated automatically from the map. Pan/zoom the map to the exact extent you want first.

Build an inset / locator map

Pan and zoom the basemap. Optionally add a data layer or draw a locator box. “Add to layout” captures a snapshot you can move and resize on the page.

Export layout

Margin guides and live-embed previews are excluded automatically. Live embeds print as placeholders — swap them for image frames before submitting.

Add live embed (on-screen preview)

Paste the URL from ArcGIS Online Map Viewer's Embed map button (the map must be shared publicly). It displays live and interactive on screen, but exports as a placeholder — use an image map frame for the submitted version.
