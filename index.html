Quick start

Two ways to work:

A. Map Maker → Layout (all in this tool). Add data in Map Maker, filter and symbolize it, then click Send to Composer — your styled map arrives as a map frame with the scale already calibrated and a legend built from your symbology.

B. Bring your own map image. Made a map elsewhere (any GIS or graphics software)? Export it as an image and upload it in the Layout module via Map Frame, then calibrate the scale bar by drawing a reference line of known distance.

Map Maker basics.

The + Add data menu takes uploads (GeoJSON, CSV with lat/long, zipped shapefile), your data library, and online sources: Natural Earth base layers, OpenStreetMap features for your map area, open-data portal search, or any GeoJSON/CSV/feature-service URL. Select a layer to set its symbology (single, categories, graduated colour with equal interval / quantile / natural breaks / manual classification, graduated symbol size), filters, and labels. The attribute table includes the filter builder and Field Calculator (e.g. rate = count / population * 1000). Spatial tools: buffer, select by location, points-in-polygons statistics, clip, erase, intersect, union, dissolve, merge, centroids, convex hull, bounding box, simplify, nearest-neighbour join, and distance matrix. The ⬇ button on each layer exports valid GeoJSON or CSV, including calculated fields. The ⟨ ⟩ buttons collapse the side panels.

Projections.

The Projection selector switches the map from the Web Mercator editing view into any of 13 projections — world (Equal Earth, Robinson, Winkel Tripel, Mollweide, Mercator, Orthographic), regional conic (Albers, Lambert Conformal, with adjustable centre and standard parallels), azimuthal (Equidistant, Stereographic), and historical (Gall–Peters, Goode, Bonne). Projected view draws your vector layers with an optional graticule and world-land backdrop; raster basemaps can't be reprojected in the browser, so they hide. Send to Composer captures the projected map (scale bars don't apply — scale varies across a projection).

Layout basics.

Start from a Template if you like — double-click any placeholder to fill it with the real element in that exact spot. Add title, text, legend, north arrow, scale bar, neatline, images. Everything drags, resizes, and rotates. Undo with Ctrl+Z. The Margins button shows 0.5" margin guides (never exported). A Live Embed shows an interactive web map on screen for reference but prints as a placeholder — use a real image frame for the final export.

Scale bars.

Scale bars link to a map frame. Frames sent from Map Maker (in Web Mercator view) are calibrated automatically. For uploaded images, select the frame, click Calibrate scale, click two points with a known real-world distance between them, and enter the distance. The bar resizes automatically if you resize the frame.

Projects and the data library.

The 🏠 home screen lists all your projects (stored in this browser — nothing goes to a server) with rename, duplicate, delete, import, and export. The project dropdown in the top bar jumps between them; work is autosaved as you go. Datasets live in a shared Data library usable across projects — "+ Add data → From my library" adds one to the current project. On shared computers, always download a project file or archive as backup before you leave.

Exporting.

Export covers everything: the layout as print-ready PDF/PNG; the Map Maker view as a georeferenced PNG with world file (usable in other GIS software); all data layers as a zip of GeoJSON files; or a full project archive (layout + layers + project file) — the complete package in one download.

About this tool.

Carto Studio was created by Jonathan Cinnamon (Geography, UBC Okanagan). It's free to use and runs entirely in your browser — your data stays on your computer. Basemap tiles and online data sources are the only network requests your data workflow makes.

Send map to Layout

The current map view will be captured as a high-resolution image and placed on the layout page, with the scale calibrated automatically from the map. Pan/zoom the map to the exact extent you want first.

Build an inset / locator map

Margin guides and live-embed previews are excluded automatically. Live embeds print as placeholders — swap them for image frames before submitting.

Share this map

Your styled, interactive map is packed into a link — no upload, no account, nothing sent to a server. Anyone who opens the link sees the live map: pan, zoom and click. Paste the embed code into ArcGIS StoryMaps (an Embed block) or any web page.

Add data from online sources

Natural Earth — the standard public-domain base layers used in professional cartography.

Fetches live OpenStreetMap features inside the current Map Maker view — zoom to your study area first. Community-contributed data: coverage and quality vary.

Results are capped at 8,000 features per query. Complex multipolygon features may be omitted.

Examples: a .geojson export link from any open data portal, or an Esri REST endpoint ending in /FeatureServer/0. The source must allow cross-origin access (most public portals do).

Add from data library

Datasets from all your projects. Adding one creates a new layer in the current project that references the shared dataset.

Add live embed (on-screen preview)

Paste an embed URL from a publicly shared web map (e.g. a map viewer's “Embed map” option). It displays live and interactive on screen, but exports as a placeholder — use an image map frame for the final version.
